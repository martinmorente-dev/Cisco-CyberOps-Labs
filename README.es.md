## Sobre este repositorio
Cada laboratorio tiene su propia carpeta con un README breve y un **write-up completo en PDF**, escrito con mis propias palabras y con mis propias capturas. Se centran en habilidades prácticas de SOC: analizar amenazas, trabajar con Windows y Linux, y leer logs y tráfico de red.
